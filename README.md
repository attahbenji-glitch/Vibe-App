# Vibely

**Connect. Share. Vibe.**

A modern social app prototype built with Expo and React Native.

## Included
- Home feed with sample posts and stories
- Videos placeholder
- Create-post interface
- Chat list prototype
- Profile screen
- Bottom navigation

## Important
This is the first UI foundation, not a production social network yet. Sample posts and chats are local demo content. Real accounts, server-side posts, private/group messaging, end-to-end encryption, media uploads, notifications, and voice/video calls require backend services and additional implementation.

## Start
Install Node.js LTS, then run:

```bash
npm install
npx expo start
```

For Android APK builds, configure an Expo account and EAS Build.
